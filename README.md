# MSpace 1.0

Android-first Expo (React Native) app for MSpace Mlang.

Brand: MSpace 1.0 / Clyde A / lightants. Gold #C4A35A on near-black.
Social: Instagram + Facebook @mspacemind.
Live space: MSpace Mlang, 2nd Floor Aqua Verde Commercial Building, Mlang, North Cotabato. Hours 9:00-18:00.

## Run
npm install then npx expo start. Expo Go on Android. tsc --noEmit for types.

## Tabs
Book Alerts Food Member Review — see src/screens.

## partners.json
Fill src/data/partners.json with real shops only.

## Build later
Use EAS for Android APK when ready. See src/constants/config.ts.

## Details
- Book default tab; membership flag in AsyncStorage switches to PHP 45/hr.
- No invented partners, phones, or Maps Place IDs.
- No API keys or FCM secrets bundled.
